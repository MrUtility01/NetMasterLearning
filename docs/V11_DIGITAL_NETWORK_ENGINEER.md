# NetMaster V11 — Digital Network Engineer

V11 turns the V10 correlation layer into an Evidence-driven Engineering OS.

## Core principle
Every conclusion must trace back through:

**Network State → Evidence → Causal Relation → First Divergence → Discriminating Test → Root Cause → Remediation → Verification → Learning**

## V11 modules
- Engineering Evidence Chain
- Causal Reasoning / First Divergence
- Dependency Blast Radius
- Controlled Failure Injection linked to Digital Twin
- Engineering Passport based on evidence, not attendance
- V11 Web/PWA workspace with offline assets
- Android Engineer OS screen using the same deterministic reasoning model

## Evidence model
Supported evidence classes include Packet, Log, Config, Metric, State, Test Result and Observation. Hard evidence is weighted above narrative symptoms. Hypotheses expose falsifiers and next tests.

## Failure injection
Every injected case defines: symptom, expected evidence, first divergence, remediation and rollback. Injection is restricted to the internal simulator/Digital Twin; no real-device configuration is executed.

## Existing capabilities preserved
V9.1 770 expert lessons, RAG, local LLM adapters, PCAP parser, packet filter, config diff, Incident Workspace, Knowledge Graph, adaptive mastery, Digital Twin and command simulator remain part of the unified project.
