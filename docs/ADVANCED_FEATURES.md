# Advanced Product Roadmap

- Spaced Repetition بر پایه عملکرد واقعی
- Adaptive Learning: سختی درس بر اساس خطاها و زمان پاسخ تغییر کند
- Skill Graph: ارتباط Protocol → Command → Lab → Failure → Quiz
- Personal Knowledge Graph
- AI Mentor با RAG
- AI Troubleshooting Copilot
- AI Lab Generator
- Config Reviewer
- Log/Syslog Explainer
- Packet Capture Assistant
- Runbook Generator
- Flashcard Generator
- Quiz Generator با difficulty تطبیقی
- Study Planner و Calendar
- Offline-first و Sync اختیاری
- JSON/ZIP Backup و Restore
- Import Content Pack بدون تغییر APK
- Versioned Content Packs
- Citation/Source tracking
- Audit Log
- Accessibility و فونت قابل تنظیم
- RTL/English terminology
- Tablet/Desktop-ready layout
