# NetMaster 7.0 — AI-Native Professional Blueprint

## هدف
NetMaster از یک اپ آموزشی به یک Personal IT Academy + Lab Orchestrator + Troubleshooting Knowledge System تبدیل می‌شود.

## 1. Adaptive Learning Engine
- هر مهارت امتیاز مستقل دارد.
- عوامل: accuracy, response_time, repetition, lab_success, troubleshooting_success, confidence.
- هر خطا یک evidence است، نه فقط یک نمره.
- موتور مرور فاصله‌دار، درس بعدی را بر اساس ضعف واقعی انتخاب می‌کند.

## 2. Skill Graph
رابطه‌ها:
Concept -> Protocol -> Packet -> Command -> Configuration -> Lab -> Failure -> Evidence -> Fix -> Quiz

مثال:
TCP -> SYN -> MSS -> Wireshark filter -> retransmission -> MTU/MSS failure -> evidence -> correction.

## 3. AI Mentor
حالت‌ها:
- Teacher: توضیح از ساده تا حرفه‌ای
- Socratic: فقط سؤال هدایت‌کننده
- Examiner: مصاحبه فنی
- Troubleshooter: فرضیه و تست
- Lab Coach: راهنمایی بدون لو دادن پاسخ
- Reviewer: بررسی پاسخ/کانفیگ

## 4. AI Troubleshooting Copilot
ورودی:
Symptom + Device + Topology + Logs + Commands + Packet Capture

خروجی:
Timeline -> hypotheses -> confidence -> evidence needed -> safe tests -> diagnosis -> remediation -> validation -> rollback.

اصل ایمنی: هیچ تغییر Production بدون تأیید کاربر و مرحله validation پیشنهاد نمی‌شود.

## 5. AI Lab Generator
از یک هدف، سناریو تولید می‌کند:
- topology
- addressing
- requirements
- baseline
- tasks
- injected fault
- expected evidence
- grading rubric
- reset/rollback

## 6. Packet Intelligence
- توضیح packet به زبان ساده
- TCP state reconstruction
- DNS transaction reconstruction
- DHCP DORA reconstruction
- ARP conversation map
- SIP call-flow reconstruction
- retransmission/latency/loss evidence

## 7. Config Intelligence
برای Cisco/MikroTik/Linux/Windows:
- syntax sanity
- dependency check
- security smell detection
- blast radius
- diff explanation
- rollback plan

## 8. Knowledge Graph
یادداشت شخصی فقط متن نیست؛ به Lesson, Device, IP, VLAN, Protocol, Command, Incident و Lab متصل می‌شود.

## 9. Incident Journal
هر رخداد:
Symptoms -> Detection -> Evidence -> Timeline -> Root Cause -> Fix -> Validation -> Lessons Learned -> Runbook

## 10. Career Mode
برای هر حوزه:
Foundation -> Associate -> Professional -> Specialist -> Architect
و پروژه‌های واقعی برای اثبات مهارت.

## 11. AI & Network Capstone
پروژه نهایی:
Zabbix + MikroTik + Syslog + Packet Capture + Knowledge Base + Local LLM/RAG + Troubleshooting Agent.

## 12. Privacy
- Local-first data
- اختیاری بودن AI cloud
- امکان Local/Private AI
- حذف/Export کامل داده کاربر
- Secretها در plain text ذخیره نشوند.
